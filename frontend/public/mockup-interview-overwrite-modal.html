BƯỚC 6 / 6: PHÂN TÍCH ĐỊNH TÍNH SAU PHỎNG VẤN

Studio Phân Tích & Đối Chiếu Tam Giác Phỏng Vấn

Bóc băng đa phương thức, kiểm soát chất lượng dữ liệu và hợp nhất góc nhìn giáo viên với bằng chứng video quan sát.

1. Trạng Thái Bình Thường (Sẵn Sàng Kéo Thả)

Hỗ trợ click mở file picker HOẶC kéo thả trực tiếp file audio vào khung.

Kéo & thả file ghi âm vào đây hoặc Click chọn Định dạng hỗ trợ: MP3, M4A, WAV, OGG (Tối đa 100MB)
2. Trạng Thái Đang Kéo File Vào (Drag Hover Active)

Viền chuyển xanh lá, nền sáng, icon nở to tạo phản hồi thị giác tức thì.

Thả file ghi âm vào đây để tải lên! Đang nhận file audio từ máy tính của bạn...
3. Xem Trước Modal Xác Nhận Ghi Đè (Smart Overwrite Modal)

Xác nhận ghi đè dữ liệu phỏng vấn

Giáo viên T01 đã có dữ liệu phỏng vấn trong hệ thống. Hãy chọn cách xử lý với file mới:

File hiện tại: interview_t01_raw.mp3
Đơn vị ý nghĩa: 14 đơn vị
Trích dẫn tiêu biểu: 3 câu
Chỉ thay thế file âm thanh gốc KHUYÊN DÙNG
Cập nhật file audio mới cho trình phát phát lại. Bảo toàn nguyên vẹn các chỉnh sửa văn bản bóc băng, đơn vị ý nghĩa (Meaning Units) và trích dẫn đã phân loại trước đó.
Làm mới toàn diện cho giáo viên T01 XÓA & PHÂN TÍCH LẠI
Xóa bản ghi cũ, đơn vị ý nghĩa và trích dẫn riêng của giáo viên này để tiến hành bóc băng AI lại từ đầu. Không ảnh hưởng đến các giáo viên khác trong tập mẫu.
